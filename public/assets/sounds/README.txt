# Sons optionnels

Placez ici un fichier `ambient.mp3` si vous voulez une musique ambient en boucle (à la place du drone synthétisé).

Source suggérée (libre de droit) : https://incompetech.com/music/royalty-free/music.html

Sans ce fichier, un drone synthétisé léger est joué en fond si la musique est activée dans les paramètres.
